Análisis de precios de libros

Proyecto de programación para análisis de datos

Descripción del proyecto

Este proyecto utiliza técnicas de web scraping con Python para recopilar y analizar información sobre los precios de libros publicados en un sitio web de práctica.

Los datos obtenidos se organizaron y procesaron para identificar el comportamiento de los precios y presentar sus principales resultados de forma visual.
